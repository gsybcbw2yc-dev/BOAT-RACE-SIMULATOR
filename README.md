# BOAT RACE SIMULATOR v0.2

仮想資金だけで競艇の予想・資金管理を楽しむ、ビルド不要のブラウザゲーム。

## 起動

- `index.html` をブラウザで開くか、GitHub Pages の公開リポジトリのルートに置く。
- 外部ライブラリ、API キー、バックエンド不要。ネットワーク通信は行わない。
- `private-race-pack.json` はユーザー本人用のデータ。公開リポジトリへ追加せず、トップ画面の「レースデータを読み込む」から選択する。未読み込み時は架空プロフィールのデモになる。
- データ読み込み後に新規の架空モードを開始すると、実在選手の保存プロフィールを使用する。開始済みの架空ゲームは途中でプロフィールを変えない。

## 実装済み

- 実戦 / 独立検証の2つの入口。架空 / 実在の別々の4セーブ。AIの公開タイミングを分離。
- 48R/日の架空開催、締切時刻順の進行、任意参加・見送り、就寝、生活費3難易度。
- 初期資金10万円、赤字時の1万円単位借入、上限10万円、日利1%、任意返済、純資産7日連続負でゲームオーバー。
- 全7舟券種、通常・フォーメーション・ボックス・流し・オッズ投票、100円単位の一括・個別金額設定。展開された買い目の重複除外、既存ベットとの合算、点数・購入合計・残高の確認。架空オッズ変動、確定結果の払戻、速度可変Canvas観戦とスキップ。
- 3連単120通り、1–3着確率、実験モデル要因寄与、期待回収倍率、第1M模式図、決まり手の仮説確率。任意のプレイヤー予想記録。
- 参加・見送り・未選択を区別して研究ログ生成。モデル別指標、券種別、会場別、最大ドローダウン、CSV/JSON出力。
- IndexedDB自動保存（不可の場合LocalStorage）、セーブファイルのエクスポート・インポート。

## データと検証上の制約

- 実在リプレイは別途取得したデータパックから、締切前に保存された予測・3連単オッズ・通常結果・公式3連単払戻の照合が成立したレースのみを読み込む。選手の平均STが欠損する場合、実験モデルで当該効果をゼロにし、架空カードの抽選対象から除く。実データはこの公開リポジトリに含めない。
- 入力元の公開時刻は独立検証されていない。アーカイブの全舟券払戻と実測STを使用するが、3連単以外の締切前オッズと第1Mの現実の順位は未収録。公式照合済みと呼べるのは3連単の着順と払戻のみ。アニメーションは模式的な再現。
- 実験モデル EXP-PL-0.1 は事前入力による仮説モデルで、実データで学習したモデルではない。結果生成・市場・予測は別アルゴリズム。架空レースはモデルの予測性能を証明しない。
- 既存 V4-PL-2026-10-12 は実在レースに付属する締切前保存分布を比較に使用する。V4の実行エンジンそのものは未移植のため、架空レースでのV4再計算には対応しない。実在リプレイは取得済みの日付とレースに限定される。
- 実在オッズは原データの単一スナップショットを表示し、変動を捏造しない。全7券種の正しい払戻で精算するが、未保存オッズは未保存と表示する。
- 研究ログはクライアント側のため、再現可能性のある学習用データであり、改ざん耐性・厳密な前向き監査は保証しない。公開版はソースコードだけを配布すること。

## テスト

`node test.cjs` — 投票方式別の組み合わせ生成と金額・重複処理、500架空レース、全7券種、確率合計、決定論的なレース結果、実在パック照合（パックがある場合）、借入と7日連続破産判定。
